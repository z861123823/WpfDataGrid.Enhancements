## 1. 简介与功能清单

本增强包为原生 WPF `DataGrid` 提供**零侵入**的能力扩展：以 `Microsoft.Xaml.Behaviors` 行为（Behavior）为主、静态附加属性为辅，不要求继承、不替换控件，可随时挂载 / 摘除。

### 1.1 开源版（免费，MIT）

| 能力 | 说明 |
| --- | --- |
| 列头过滤弹窗 | 每列生成过滤按钮，弹出内置 `FilterPanel`，支持文本 / 数值 / 日期 / 枚举四类编辑器 |
| 多列组合过滤 | 列间 AND 语义，列内支持 AND / OR 谓词组合，基于 `ICollectionView.Filter` |
| 编程式过滤 | `ApplyColumnFilter` / `ClearColumnFilter` / `FilterModel` 完整编程接口 |
| 自定义谓词 | `IFilterPredicate` 接口开放，任意类型均可扩展匹配逻辑 |
| CSV 导出 | UTF-8 BOM + RFC 4180 转义，Excel 直接打开中文不乱码 |
| 主题系统 | 内置浅色 / 深色 / 跟随系统三档，支持运行时注册自定义主题 |
| 列宽自动识别 | `DataGridAutoFit` 按内容自动测量列宽（采样 / 全量两种模式） |
| 行为基座 | `DataGridBehaviorBase` 开放，可派生自己的 DataGrid 行为 |

### 1.2 商业版（Pro，闭源）

Pro 版是开源版的**严格超集**，同一命名空间，安装 Pro 包即可获得以下额外能力：

| 能力 | 说明 |
| --- | --- |
| XLSX 导出 | 原生 xlsx（免 COM，Sylvan.Data.Excel 流式写入），表头样式 / 自动列宽 / 冻结表头 |
| PDF 导出 | A4 纵向 / 横向，表头 / 分页 / 页眉标题 / 页码 |
| 正则过滤 | `RegexPredicate` 谓词（AdvancedFilter 功能） |
| 大数据虚拟化 | `AsyncVirtualizingCollection<T>` 分页加载 + 滚动窗口化，面向 10 万+ 行 |
| 授权管理 | RSA-2048 签名离线许可证，试用期 / 功能掩码 / 激活校验 |

> **免费 / Pro 边界**：免费版不含 XLSX、PDF 导出、正则过滤、异步虚拟化与授权管理。调用 Pro 功能前建议用 `LicenseManager.EnsureLicensed(...)` 做权限校验（见 [4.6 许可](#46-许可licensemanager-与试用激活)）。

## 3. 快速上手

### 3.1 最小示例：挂行为、开过滤

```xml
<DataGrid x:Name="Grid"
          ItemsSource="{Binding Orders}"
          AutoGenerateColumns="False"
          CanUserAddRows="False"
          enh:EnableFiltering="True"
          enh:EnableExporting="True"
          enh:ThemeMode="System"
          enh:AutoFitColumns="True">
    <DataGrid.Columns>
        <DataGridTextColumn Header="订单号" Binding="{Binding OrderNo}" />
        <DataGridTextColumn Header="客户" Binding="{Binding Customer}" />
        <DataGridTextColumn Header="金额" Binding="{Binding Amount}" />
        <DataGridTextColumn Header="日期" Binding="{Binding CreatedAt}" />
    </DataGrid.Columns>
</DataGrid>
```

仅上面 XAML 即可获得：每列列头出现漏斗过滤按钮 → 点击弹出过滤面板；CSV 导出 / 主题 / 列宽自动适配能力也已挂载。

等价的行为写法（适合代码动态挂载）：

```csharp
using System.Windows.Controls;
using Microsoft.Xaml.Behaviors;
using WpfDataGrid.Enhancements.Filtering;
using WpfDataGrid.Enhancements.Exporting;

var grid = new DataGrid();
var behaviors = Interaction.GetBehaviors(grid);

behaviors.Add(new DataGridFilterBehavior());
behaviors.Add(new DataGridExportBehavior());
```

> 说明：`EnableFiltering="True"` 附加属性内部等价于向 `Interaction.GetBehaviors(dataGrid)` 添加 `DataGridFilterBehavior`；置 `False` 或移除属性时行为自动摘除并恢复原列头。

### 3.2 代码调用：编程式过滤

```csharp
// 获取已挂载的行为
var behavior = Interaction.GetBehaviors(grid)
    .OfType<DataGridFilterBehavior>()
    .First();

// 为 "Customer" 列应用"以"张"开头的文本过滤（忽略大小写）
behavior.ApplyColumnFilter(
    "Customer",
    new IFilterPredicate[] { new TextContainsPredicate("张", ignoreCase: true, TextMatchMode.StartsWith) });

// 清除该列过滤
behavior.ClearColumnFilter("Customer");

// 一键清除全部过滤
behavior.FilterModel?.Clear();
```

### 3.3 代码调用：导出

```csharp
var export = Interaction.GetBehaviors(grid)
    .OfType<DataGridExportBehavior>()
    .First();

// 导出当前过滤后的视图为 CSV（开源版内置）
export.Export(ExportScope.CurrentView, @"D:\out\orders.csv");

// Pro：导出为 xlsx（带进度回调）
export.Export(ExportScope.AllData, @"D:\out\orders.xlsx", new Progress<int>(p => StatusText.Text = $"{p}%"));
```

## 4. 核心功能使用

### 4.1 列头过滤弹窗

行为会在每个可过滤列（存在绑定路径 / `SortMemberPath` / 非空列头的列）的列头右侧生成过滤按钮，点击弹出过滤面板（Popup 承载，点击面板外关闭）。

内置 `FilterPanel` 按列类型自动选择编辑器：

| 列类型 | 编辑器 | 规则 |
| --- | --- | --- |
| `string` | 文本框 + 模式下拉 | 包含（默认）/ 前缀 / 后缀；忽略大小写开关；输入后 300ms 防抖即时过滤 |
| 数值（int / double / decimal 等） | 条件下拉 + 数值框 | 区间 [最小, 最大]（默认）/ 等于 / 大于 / 小于 |
| `DateTime` / `DateTimeOffset` | 起止日期选择器 | 闭区间；结束日期取当天 23:59:59.999，保证"某日"含全天 |
| `bool` / 枚举 | 多选勾选（可滚动） | 勾选值取并集；提供"全选 / 全不选" |
| 其他类型 | 提示文案 | 内置编辑器不支持，请使用自定义谓词（见 [5.1](#51-自定义-ifilterpredicate)） |

已启用过滤的列，按钮会以主题强调色高亮（加粗）提示。

### 4.2 编程式过滤：FilterModel / ColumnFilter / 谓词组合

过滤状态统一保存在 `DataGridFilterBehavior.FilterModel`（`FilterModel` 类型）：

- `FilterModel`：列名 → `ColumnFilter` 的字典；列间 **AND** 语义；模型变化触发 `Changed` 事件，由行为刷新视图。
- `ColumnFilter`：单列条件集合；列内谓词按 `Combination`（`And` 默认 / `Or`）组合；`Matches` 判断单元格值是否满足。
- 谓词（`IFilterPredicate`）：`TextContainsPredicate` / `NumericRangePredicate` / `DateRangePredicate` / `EnumMultiSelectPredicate`（开源）；`RegexPredicate`（Pro）。

#### 4.2.1 内置谓词速查

```csharp
using WpfDataGrid.Enhancements.Filtering;

// 文本：包含 / 前缀 / 后缀，可忽略大小写
new TextContainsPredicate("华东", ignoreCase: true, TextMatchMode.Contains);
new TextContainsPredicate("A-", ignoreCase: false, TextMatchMode.StartsWith);
new TextContainsPredicate("Ltd", ignoreCase: true, TextMatchMode.EndsWith);

// 数值：区间 / 等于 / 大于 / 小于（模式取 Equals / GreaterThan / LessThan 时第二个参数为单值目标）
new NumericRangePredicate(100, 500, NumericCompareMode.Between);
new NumericRangePredicate(100, null, NumericCompareMode.GreaterThan);

// 日期：闭区间（含边界）
new DateRangePredicate(new DateTime(2026, 1, 1), new DateTime(2026, 12, 31));

// 枚举 / 布尔多选：任一勾选即保留
new EnumMultiSelectPredicate(new object[] { OrderStatus.Paid, OrderStatus.Shipped });
```

> 注意：`NumericCompareMode` 枚举成员为 `Equals` / `Between` / `GreaterThan` / `LessThan`；`TextMatchMode` 为 `Contains` / `StartsWith` / `EndsWith`。

#### 4.2.2 列内 OR 组合示例（同列多谓词任一满足）

```csharp
var model = behavior.FilterModel;                    // 为 null 时行为会自动创建
var column = model.GetOrAdd("Status");               // 获取或创建该列条件
column.Combination = PredicateCombination.Or;        // 列内改 OR
column.AddPredicate(new EnumMultiSelectPredicate(new object[] { OrderStatus.Paid }));
column.AddPredicate(new EnumMultiSelectPredicate(new object[] { OrderStatus.Shipped }));
model.Invalidate();                                  // 手动通知模型变化（GetOrAdd 新增列不触发 Changed）
```

#### 4.2.3 编程接口与事件触发

- `bool ApplyColumnFilter(string columnName, IEnumerable<IFilterPredicate> predicates)`：替换该列全部谓词；空集合等价清除。触发 `Filtering`（可取消）与 `Filtered`。
- `bool ClearColumnFilter(string columnName)`：清除该列。触发 `Filtering` / `Filtered`（谓词为空）。
- `void ApplyFilter()`：将当前模型应用到 `ICollectionView.Filter` 并刷新视图。
- 直接改 `FilterModel` 后调用 `Invalidate()` 同样触发视图刷新，但**不会**经过 `Filtering` / `Filtered` 事件（事件只由 `ApplyColumnFilter` / `ClearColumnFilter` 触发）。

### 4.3 主题：DataGridThemeManager 与自定义主题注册

#### 4.3.1 内置三档主题

```csharp
using WpfDataGrid.Enhancements.Theming;

DataGridThemeManager.ApplyTheme(ThemeMode.System);   // 跟随系统（监听系统主题变更自动切换）
DataGridThemeManager.ApplyTheme(ThemeMode.Light);    // 浅色
DataGridThemeManager.ApplyTheme(ThemeMode.Dark);     // 深色
DataGridThemeManager.ClearTheme();                   // 移除已合并的主题字典
```

XAML 声明式（等价，且处理启动时序：DataGrid `Loaded` 后自动重放一次主题刷新 DynamicResource）：

```xml
<DataGrid enh:ThemeMode="Dark" ... />
```

#### 4.3.2 注册并切换自定义主题

```csharp
var dictionary = new ResourceDictionary
{
    Source = new Uri("pack://application:,,,/MyApp;component/Themes/Corporate.xaml", UriKind.Absolute)
};

DataGridThemeManager.RegisterTheme("Corporate", dictionary);
DataGridThemeManager.ApplyTheme("Corporate");        // 返回 bool：false 表示未注册
```

- 主题名称**不区分大小写**；同名重复注册会替换旧字典，若该主题正生效会立即重新合并。
- 自定义字典中的资源键与内置主题对齐（`DataGridEnhancements.*`，见 [5.5](#55-资源键覆盖换肤)）即可完整覆盖配色；未覆盖的键回退到内置值。
- 查询：`RegisteredThemeNames` / `TryGetRegisteredTheme(name)` / `AppliedCustomThemeName` / `IsCustomThemeApplied`。

### 4.4 导出：Xlsx / Csv（Pro 另含 PDF）

`DataGridExportBehavior` 负责收集数据（列头 + 行值），委托给 `IExportProvider` 写出。内置注册 CSV Provider；Pro 版可注入 XLSX / PDF Provider。

#### 4.4.1 导出范围

| `ExportScope` | 含义 |
| --- | --- |
| `CurrentView` | 当前过滤后的视图行（默认） |
| `SelectedRows` | 仅选中的行 |
| `AllData` | 忽略过滤的全量数据 |

#### 4.4.2 CSV 导出（开源内置）

```csharp
// 默认行为已内置 CsvExportProvider（UTF-8 BOM，Excel 中文不乱码；RFC 4180 转义）
export.Export(ExportScope.CurrentView, @"D:\out\orders.csv");

// 关闭 BOM
export.Providers.OfType<CsvExportProvider>().First().WriteBom = false;
```

#### 4.4.3 XLSX 导出（Pro）

```csharp
using WpfDataGrid.Enhancements.Pro.Exporting;

var xlsx = new XlsxExportProvider
{
    WorksheetName = "订单明细",        // 覆盖 TableData.WorksheetName；为空用默认 "Sheet1"
    StyleHeader = true,                 // 表头加粗 + 背景色 + 边框
    AutoColumnWidth = true,             // 按内容自动列宽（8~60 字符）
    FreezeHeaderRow = true,             // 冻结表头行
    MinColumnWidth = 8,
    MaxColumnWidth = 60,
};

export.ExportProvider = xlsx;           // 或加入 Providers 集合后按扩展名自动选择
export.Export(ExportScope.AllData, @"D:\out\orders.xlsx", new Progress<int>(p => ...));
```

> 基于 Sylvan.Data.Excel 流式写入，大文件内存占用不随数据量增长；免 Office COM。

#### 4.4.4 PDF 导出（Pro）

```csharp
using WpfDataGrid.Enhancements.Pro.Exporting;

var pdf = new PdfExportProvider
{
    Orientation = PdfExportProvider.PageOrientation.Landscape,  // 横向
    Title = "2026 年度订单",                                    // 页眉标题
};
export.Providers.Add(pdf);
export.Export(ExportScope.CurrentView, @"D:\out\orders.pdf");
```

- A4 页面（`PdfExportProvider.PageSize.A4Width` / `A4Height`，单位磅）；表头行 + 数据分页 + 列宽均分自适应 + 页码。

#### 4.4.5 按扩展名自动选择

`Export(scope, filePath)` 未设置 `ExportProvider` 时，按目标文件扩展名在 `Providers` 中查找 `FileExtension` 匹配的 Provider；找不到抛 `InvalidOperationException`。

### 4.5 列宽 AutoFit

```xml
<DataGrid enh:AutoFitColumns="True"
          enh:AutoFitMode="Sample"
          enh:SampleSize="100"
          enh:MinColumnWidth="80"
          enh:MaxColumnWidth="400"
          enh:StarLastColumn="True">
```

| 附加属性 | 默认值 | 说明 |
| --- | --- | --- |
| `AutoFitColumns` | `false` | 启用自动列宽 |
| `AutoFitMode` | `Sample` | `Sample`（采样前 `SampleSize` 行，大数据集推荐）/ `Full`（全量遍历，≤5000 行自动回落 Sample） |
| `SampleSize` | `100` | 采样行数 |
| `MinColumnWidth` / `MaxColumnWidth` | `NaN` | 列宽约束（NaN 表示不限制） |
| `StarLastColumn` | `false` | 最后一列 `*` 填充剩余空间，其余列按内容定宽 |

- 测量基于表头文本与单元格内容（`FormattedText`），不修改任何样式，与主题 / 自定义 Cell 模板 / 过滤面板 / 虚拟化共存。
- 触发时机：`Loaded`、`ItemsSource` 变化、配置属性变化；内部按阈值收敛（变化 <0.5px 不写 `Width`），避免布局死循环。
- 代码方式：`DataGridAutoFit.Apply(grid)`。

### 4.6 许可：LicenseManager 与试用 / 激活

Pro 功能采用**离线许可证 + RSA-2048 签名**（RSA-SHA256，PKCS#1 v1.5）校验，库内仅嵌公钥。无许可证时进入试用模式。

#### 4.6.1 校验状态

```csharp
using WpfDataGrid.Enhancements.Pro;

var status = LicenseManager.ValidateLicense();   // LicenseStatus
if (LicenseManager.IsLicensed) { /* 已激活 */ }
```

`LicenseStatus`：`Valid` / `Trial` / `TrialExpired` / `Expired` / `SignatureInvalid` / `Corrupted`。

#### 4.6.2 功能掩码与权限校验

```csharp
// ProFeature: XlsxExport / PdfExport / AdvancedFilter / AsyncVirtualization / All
if (LicenseManager.IsFeatureEnabled(ProFeature.XlsxExport)) { /* 允许 xlsx */ }

// 强制校验：未授权抛 LicenseException（携带 LicenseErrorCode）
try
{
    LicenseManager.EnsureLicensed(ProFeature.PdfExport);
    export.Export(ExportScope.AllData, @"D:\out\orders.pdf");
}
catch (LicenseManager.LicenseException ex)
{
    MessageBox.Show($"功能未授权：{ex.ErrorCode}");
}
```

#### 4.6.3 试用期配置

```csharp
LicenseManager.TrialDays = 60;            // 默认 30 天
LicenseManager.TrialMaxRows = 10000;      // 默认 5000 行（单次导出）
LicenseManager.TrialStateFilePath = ...;  // 试用状态文件路径（默认 %LocalAppData%\WpfDataGrid.Enhancements\）
var remaining = LicenseManager.GetTrialRemainingDays();
var maxRows = LicenseManager.GetTrialMaxRows();
```

#### 4.6.4 激活

将签发工具生成的许可证文件（默认文件名 `wpfdatagrid.enhancements.license`）放置到 `LicenseManager.LicenseFilePath`（默认 `%LocalAppData%\WpfDataGrid.Enhancements\wpfdatagrid.enhancements.license`），程序下次调用 `ValidateLicense()` 即自动校验生效。路径可重定向：

```csharp
LicenseManager.LicenseFilePath = @"D:\licenses\my.license";
LicenseManager.ResetCache();   // 文件更新 / 路径变更后清缓存重新校验
```

许可证内容（`LicenseDocument`）：`LicenseId` / `LicenseType`（Personal / Team / Enterprise）/ `HolderName` / `HolderEmail` / `IssuedAtUtc` / `ExpiresAtUtc`（null 为永久）/ `FeatureMask`。

### 4.7 大数据虚拟化（Pro）

`AsyncVirtualizingCollection<T>` 按需分页加载 + 滚动窗口化 + 内存缓存，面向 10 万+ 行只读场景。

```csharp
using WpfDataGrid.Enhancements.Pro.Performance;

var collection = new AsyncVirtualizingCollection<Order>(
    pageLoader: (offset, count) => orderService.Fetch(offset, count),   // PageLoader 委托
    pageSize: 200,
    totalCount: 100_000,
    marshal: action => Dispatcher.BeginInvoke(action));                 // 跨线程回调调度

grid.ItemsSource = collection;
```

- 对外表现为固定 `TotalCount` 的只读 `IList<T>`；索引未加载行触发后台异步加载，加载完 Reset 刷新视图。
- 关键成员：`TotalCount` / `PageSize` / `LoadedCount`；`LoadPage(pageIndex)` / `LoadAll()`（排序等全量操作慎用）/ `ApplySort(propertyName, ascending)` / `SetTotalCount(totalCount)`（动态调整并保留已加载缓存）。
- 只读集合：`Add` / `Remove` / `Clear` / 索引赋值均不支持。

## 5. 扩展点

### 5.1 自定义 IFilterPredicate

实现 `IFilterPredicate`（唯一成员 `bool Match(object? value)`），即可接入任意匹配逻辑：

```csharp
using WpfDataGrid.Enhancements.Filtering;

public sealed class AmountAbovePredicate : IFilterPredicate
{
    public AmountAbovePredicate(decimal threshold) => Threshold = threshold;
    public decimal Threshold { get; }

    public bool Match(object? value)
    {
        if (value is decimal d) return d > Threshold;
        return value != null && decimal.TryParse(value.ToString(), out var v) && v > Threshold;
    }
}

// 使用：内置编辑器不支持的列类型也能编程式过滤
behavior.ApplyColumnFilter("Amount", new IFilterPredicate[] { new AmountAbovePredicate(1000m) });
```

Pro 版内置 `RegexPredicate` 即此类实现（`new RegexPredicate(@"^A-\d{4}$")`，属于 AdvancedFilter 功能）。

### 5.2 自定义 IFilterPanel 与 FilterPanelFactory 注入

`IFilterPanel` 是过滤面板抽象（成员 `FocusInput()`、`Close()`）；**实现必须同时是 `UIElement`**（如 `UserControl` / `ContentControl`），否则弹出时抛 `InvalidOperationException`。

```csharp
using System.Windows;
using System.Windows.Controls;
using WpfDataGrid.Enhancements.Filtering;

public sealed class MyFilterPanel : UserControl, IFilterPanel
{
    private readonly Action _close;
    private readonly string _columnName;

    // 构造由 FilterPanelFactory 委托按需创建；参数与委托签名对应
    public MyFilterPanel(DataGridFilterBehavior owner, string columnName, Type? propertyType, Action close)
    {
        _columnName = columnName;
        _close = close;
        Content = new Button
        {
            Content = $"自定义面板：{columnName}（点击关闭）",
            HorizontalAlignment = HorizontalAlignment.Stretch,
            VerticalAlignment = VerticalAlignment.Stretch,
        };
        ((Button)Content).Click += (_, __) =>
        {
            owner.ApplyColumnFilter(columnName, new IFilterPredicate[] { new MyPredicate() });
            _close();
        };
    }

    public void FocusInput() => Focus();
    public void Close() => _close();
}
```

注入工厂（`DataGridFilterBehavior.FilterPanelFactory`，签名为 `Func<DataGridFilterBehavior, string, Type?, Action, IFilterPanel>`）：

```csharp
var behavior = new DataGridFilterBehavior
{
    FilterPanelFactory = (owner, columnName, propertyType, close) =>
        new MyFilterPanel(owner, columnName, propertyType, close)
};
Interaction.GetBehaviors(grid).Add(behavior);
```

> 委托参数：`owner`（行为实例，可调用 `ApplyColumnFilter` / `ClearColumnFilter`）、`columnName`（列绑定路径）、`propertyType`（列属性类型，可能为 null）、`close`（关闭弹层回调）。工厂返回 null 时行为自动使用内置 `FilterPanel`。

### 5.3 DataGridBehaviorBase 派生

所有行为继承 `DataGridBehaviorBase : Behavior<DataGrid>`，可派生自己的 DataGrid 能力：

```csharp
using System.Windows.Controls;
using WpfDataGrid.Enhancements.Behaviors;

public sealed class RowDoubleClickBehavior : DataGridBehaviorBase
{
    protected override void OnAttached()
    {
        base.OnAttached();
        AssociatedObject.MouseDoubleClick += OnDoubleClick;
    }

    protected override void OnDetaching()
    {
        AssociatedObject.MouseDoubleClick -= OnDoubleClick;
        base.OnDetaching();
    }

    private void OnDoubleClick(object sender, System.Windows.Input.MouseButtonEventArgs e) { /* ... */ }
}

// 挂载
Interaction.GetBehaviors(grid).Add(new RowDoubleClickBehavior());
```

生命周期：附加时 `OnAttached`（初始化、订阅事件），分离时 `OnDetaching`（务必取消订阅、释放资源）。

### 5.4 自定义 IExportProvider

实现 `IExportProvider`（`FileExtension` + `Export(TableData, Stream)`）即可接入任意导出格式：

```csharp
using System.IO;
using System.Text;
using WpfDataGrid.Enhancements.Exporting;

public sealed class TxtExportProvider : IExportProvider
{
    public string FileExtension => ".txt";

    public void Export(TableData tableData, Stream destination)
    {
        using var writer = new StreamWriter(destination, new UTF8Encoding(true), 4096, leaveOpen: true);
        writer.WriteLine(string.Join("\t", tableData.Columns));
        foreach (var row in tableData.Rows)
            writer.WriteLine(string.Join("\t", row));
    }
}

// 注册后按扩展名自动选择
export.Providers.Add(new TxtExportProvider());
export.Export(ExportScope.CurrentView, @"D:\out\orders.txt");
```

## 8. 常见问题 FAQ

**Q1：过滤按钮显示为黑色方块 / 图标不渲染？**
过滤按钮使用主题资源 `DataGridEnhancements.FilterButton` 样式（漏斗几何以 `Fill` 绑定 `Foreground`）。请确认：① 已调用 `DataGridThemeManager.ApplyTheme(...)` 或设置了 `enh:ThemeMode`，主题字典已合并到 `Application.Resources`；② 未在窗口级定义同名 `FilterButton` 隐式样式覆盖（覆盖会吞掉主题模板）。行为在主题未就绪时自动使用等价兜底模板，正常情况下无需处理。

**Q2：某列类型内置过滤面板不支持，怎么办？**
内置面板支持文本 / 数值 / 日期 / 枚举（含 bool），其他类型面板显示提示。两种方案：① 编程式 `ApplyColumnFilter` 配合自定义 `IFilterPredicate`；② 注入自定义 `IFilterPanel`（须为 UIElement），见 [5.1](#51-自定义-ifilterpredicate) / [5.2](#52-自定义-ifilterpanel-与-filterpanelfactory-注入)。

**Q3：导出 CSV 在 Excel 打开中文乱码？**
默认 `CsvExportProvider.WriteBom = true`（UTF-8 BOM），Excel 可直接识别。若乱码请确认未将 `WriteBom` 改为 false。

**Q4：导出只有过滤后的行？**
`Export(ExportScope.CurrentView)` 导出当前视图（过滤后）。需要全量用 `ExportScope.AllData`，仅选中行用 `ExportScope.SelectedRows`。

**Q5：导出 xlsx / pdf 报"未找到可处理扩展名的 Provider"？**
确认安装了 Pro 包（xlsx / pdf Provider 在 `WpfDataGrid.Enhancements.Pro`），并已将 Provider 加入 `DataGridExportBehavior.Providers`（或设置 `ExportProvider`）。

**Q6：10 万行数据滚动卡顿？**
免费版：`AutoFitMode="Sample"` + 采样；Pro 版：`AsyncVirtualizingCollection<T>` 分页加载（滚动窗口化）。`LoadAll()` / `ApplySort` 会全量加载，大数据场景建议服务端排序后重建集合。

**Q7：试用期如何计算？结束后还能用免费功能吗？**
试用状态记录在 `TrialStateFilePath`（首次调用 `ValidateLicense()` 记录起始日）。试用结束仅影响 Pro 功能（`EnsureLicensed` 抛异常）；过滤 / CSV 导出 / 主题 / AutoFit 等开源功能不受影响。更换许可证后调用 `ResetCache()`。

**Q8：许可证激活后不生效？**
检查：① 文件路径是否为 `LicenseManager.LicenseFilePath`（默认 `%LocalAppData%\WpfDataGrid.Enhancements\wpfdatagrid.enhancements.license`）；② 文件是否由配套签发工具生成（签名必须匹配库内公钥）；③ 激活后调用 `LicenseManager.ResetCache()` 清缓存。

**Q9：自定义主题注册成功但界面没变化？**
确认自定义字典使用 `DataGridEnhancements.*` 键（见 [5.5](#55-资源键覆盖换肤)），键不一致的字典不会影响界面；主题切换后若窗口已加载，可再调用一次 `ApplyTheme` 刷新 DynamicResource。

**Q10：net462 项目能否使用？**
可以。库双 TFM `net462;net8.0-windows`，net462 项目直接引用 NuGet 包即可，无需额外配置。

**Q11：如何在运行时移除过滤能力？**
附加属性 `EnableFiltering="False"` 或从 `Interaction.GetBehaviors(grid)` 移除 `DataGridFilterBehavior`（行为分离时自动恢复原列头并清除视图 Filter）。
